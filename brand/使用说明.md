# 智变链 Logo v1

设计日期：2026-09-28。制作方式：原生矢量设计与 PNG 渲染，未使用图像生成模型。

## 设计含义

以“智”的拼音首字母 Z 为骨架，两段斜向链节交叠，表达工程变更沿关联对象传递。中央菱形留白是证据与核查节点。保持平面、几何轮廓，沿用产品界面现有的深青色与青绿色。

## 文件选择

| 文件 | 用途 |
| --- | --- |
| 智变链-横版.svg / .png | 标准组合：图标、项目名称和“工程变更影响分析智能体”说明。适合申报材料、PPT、系统首页和视频片头。 |
| 智变链-图标.svg / .png | 独立符号，适合应用图标、头像、侧栏或空间较小的位置。 |
| 智变链-横版反白.svg / .png | 适合深青、深灰等深色背景。 |
| 智变链-图标单色.svg / .png | 适合单色印刷或不便使用双色的位置。 |
| 智变链-展示预览.png | 白底展示图，便于直接查看。此文件不是透明背景。 |

横版 PNG 为 2580 × 1080，图标 PNG 为 2048 × 2048；两类均含透明通道。SVG 可以无损缩放，中文字样已经转成路径，不依赖目标电脑安装字体。PNG 预览中的留白为排版安全区域。

## 使用规则

- 主色：青绿色 `#087F77`；辅助深色：深青色 `#142E32`。反白版本使用白色与浅青绿 `#8FDBBD`。
- 保持原始长宽比，不压扁、拉长，也不添加阴影、描边或渐变。
- 图形周边留出至少约图形高度 1/5 的空白。
- 小尺寸优先使用独立图标；建议图标显示不小于 24 px。完整横版建议宽度不小于 320 px，以保证副标题可读。
- 标准双色版用于浅色底，反白版用于深色底。

字标以 Noto Sans SC 的字形轮廓制作；附上 SIL Open Font License 文本。素材包不包含完整字体文件。
