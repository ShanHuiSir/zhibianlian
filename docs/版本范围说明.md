# v1.0.0 实现范围与 PRD 差异

本文件对照既有《智变链 PRD v1.0》，记录本次源码与视频的实际边界。保留原 PRD，不将未完成需求改写成“已完成”。

## 已交付核心闭环

任务创建/搜索、资料上传与显式替换、来源预览、表格字段映射确认、精确订单范围人工确认、DeepSeek 真实图纸提取、十进制尺寸/公差比较、检验一致性、旧库存/在制品关联、单层 BOM 与订单关联、证据核查、逐项人工评审、部门建议清单、PDF/CSV 导出、历史运行、输入修订与报告快照保护。

重复文件去重、重复编号冲突、缺单位/版本冲突、缺资料覆盖提示、API 鉴权/超时/取消、旧页面评审拒绝、跨任务读取隔离均有回归测试。

## 与 PRD 的主要差异

| PRD 范围 | 本次实现与限制 |
| --- | --- |
| FR03/04 业务字段纠错 | 提供表头映射与确认；图纸提取字段可带理由修正。业务单元格纠错通过修改源文件并显式替换完成，尚无逐行原位编辑器。 |
| FR05 通用图纸提取 | 已实际调用 DeepSeek Flash 发送清晰 PDF 页面图像与文本；验证样本有限。特征需有明确编号。无文字层或自动引文核验失败时需人工确认。未验证复杂图纸识别稳定性。 |
| FR06 特征语义匹配 | 按料号、版本、特征编号及尺寸种类匹配。一对多/未知/不匹配阻断确认。尚无语义候选匹配界面。 |
| FR09/数据契约 多层 BOM | 仅支持产品到目标零件的单层显式展开；不支持多层递归或环路分析。 |
| FR10 ECN 候选生效范围 | ECN 原文可读并作为证据。生效清单由人工阅读和填写确认，不自动用模型抽取订单候选、也不自动检测所有通知与任务的语义冲突。 |
| FR11 证据支持 | 引用由服务端产生，验证归属、页码、原文匹配、关键数值及结构化标注一致性；显示整页或整行，尚无局部高亮。无法自动验证的扫描图字段需人工确认。未完成独立人工证据支持率统计。 |
| FR12 修改人工意见 | 原始数值和结论保持不变，修改作为人工意见独立记录。系统提醒返回输入修改数值，但尚无自然语言人工意见中的数值冲突检测。 |
| FR14 草稿与历史 | 分析已结束、失败或取消后可导出当前可用内容草稿；运行中不导出。报告文件与 JSON 快照固定；程序未提供所有历史报告文件的差异比较。 |
| FR15 运行统计 | 成功调用保存响应标识、耗时与 token 用量；失败记录阶段和错误，不一定保留失败响应的全部供应商统计。未估算费用。应用不复用提取结果，供应商前缀缓存用量仍可能非零。 |
| FR16 模式 | 使用“DeepSeek 真实识图”和“本地规则”两个显式模式，模拟数据另设标签。本地模式仍从当前文件计算，未实现预设答案播放模式。 |
| FR01/14 幂等 | 运行进行中重复启动返回同一运行；已完成后点击重新分析会创建新运行。导出按运行和评审修订复用快照；未提供独立 request-id API。 |
| 第14节统计验收 | 已完成自动化回归、浏览器端到端核查、真实 API 主案例与文件扰动演示；尚未建立 8 开发 / 12 锁定验收集，不给出通用准确率或稳定性承诺。 |

## 暂不包含

材料变更、多层 BOM、影响关系图、批量分析、多用户权限/审批、ERP/MES 联动、复杂 CAD 几何分析、自动换模调参或报废、自动执行部门动作。DOCX 仅正文和表格读取，不处理浮动文本框与批注。Windows 脚本未在 Windows 实机验证。

## 视频口径

视频展示实际浏览器操作，使用模拟工程资料和真实 DeepSeek 调用。解说为合成语音；字幕是讲解层，不替代程序状态。演示只描述实际出现的结果，不将单例成功当成广泛工业场景准确率。改成 5.0 mm 的图纸是独立扰动测试，不是新的正式工程批准。
