## 真实 DeepSeek 调用

通过 DeepSeek 官方 HTTPS 接口，以 `deepseek-flash` 调用 DeepSeek-V4.1-Flash。发送实际 PDF 页面 PNG 和解析文本，不读取 tests/ 中的预期答案。实际请求返回成功状态、模型标识、响应编号及 token 用量。

开发联调主案例一次完整分析用时 **4.131 秒**，两次实际模型调用分别 1.645 秒与 2.372 秒，均第一次成功。输入合计 2704 tokens，输出合计 164 tokens，平台前缀缓存命中合计 128 tokens。该次结果 H1 增加 0.5 mm，无人工修正。

最终录屏对应两轮调用的完整摘要见 `实际API运行记录.json`：第一轮主案例（4.0 → 4.5），第二轮文件扰动（4.0 → 5.0）。每轮保存实际输入哈希、运行配置、结果、请求耗时和平台 token 统计。应用未启用提取结果缓存；供应商报告的前缀缓存属于另一层缓存，不能将其写成“完全无缓存”。

以上计时是从开始分析到可查看分析结果，**不包含人工确认时间或最终 PDF 导出时间**，不等同于 PRD 中统计意义上的首份报告耗时。单一模拟场景的小规模重复不构成稳定性/效率收益证明。没有推算供应商账单费用。
