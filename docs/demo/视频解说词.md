# 智变链演示视频解说词

实际浏览器操作录屏；模拟资料；真实 DeepSeek 调用；Tingting 合成语音。无加速或跳过模型等待。

## 00:00 智变链 · 工程变更影响分析智能体

这是智变链，工程变更影响分析智能体。它面向制造企业常见的变更评审：图纸改了，检验标准有没有同步，旧料和在制品需要核查什么。接下来用模拟工业资料，展示真实程序从导入、识图到评审导出的完整过程。

## 00:21 01 / 建立任务，导入资料

先建立控制器外壳的变更任务，旧版本 A，新版本 B。这里选择真实的 Deep Seek 识图。载入模拟案例后，八份原始资料实际导入系统，包括新旧图纸、变更通知、检验标准和业务表格，并不是载入预先生成的分析答案。

## 00:42 02 / 查看原图与确认字段

先核查原始图纸。安装孔特征 H 一的新版要求为四点五毫米，上下偏差为正负零点一。再确认表格字段映射，确保料号、版本和数量含义一致。每份资料都保留文件指纹，后续结论能追溯到这一轮输入。

## 01:03 03 / 确认变更生效范围

变更通知明确规定，只对这张新订单执行 B 版，旧订单仍执行 A 版。由工程人员阅读原文、填写精确订单清单和确认依据。系统不会把看起来较新的订单编号，自动推断为全部需要换版。

## 01:22 04 / 调用 DeepSeek 真实识图

开始分析。系统实际把两份图纸的页面图片和文本发送到 Deep Seek 四点一 Flash，提取尺寸字段。接着由十进制规则引擎计算差异、关联业务对象。界面显示真实处理阶段；调用失败会报错，不会悄悄换成固定结果。

## 01:43 05 / 尺寸差异与双向证据

识别结果显示，安装孔从四点零变为四点五毫米，增加零点五毫米，公差不变。点击双向证据，可以切换查看新旧图纸原文。尺寸事实、规则推导和待核查建议会分开呈现，帮助工程人员判断依据是否充分。

## 02:04 06 / 发现检验要求冲突

在影响分析中，质量部门有一项优先处理事项。拟用于新订单的检验标准仍写四点零毫米，与新版四点五毫米不一致。打开依据可以同时核查检验表记录、新版图纸和已确认的生效范围。系统提出更新评审建议，不直接发布检验标准。

## 02:26 07 / 分清关联、冲突与范围外

旧版库存六百件、在制品两百件分别列为用途待核查，因为它们还没有分配订单，不能直接认定违规或报废。新版库存和无关料号没有被误列入旧料清单。订单表也明确显示，新订单在生效范围内，旧订单在范围外。

## 02:47 08 / 人工评审与责任落实

接下来由人完成评审。采纳尺寸事实和检验建议；对装配、库存和在制品事项，选择待核查，分别填写责任部门和所需资料。系统保留原始建议与人工决定，并生成部门处理清单。这里的完成评审，仅表示意见整理完成，不代表生产批准。

## 03:11 09 / 导出报告与处理清单

现在导出已评审报告和处理清单。报告明确标注模拟资料、真实模型分析和仍然存在的未决事项，包含尺寸差异、证据片段、人工决定和资料指纹。PDF 可以留档核查，CSV 可以交给相关部门继续处理。

## 03:33 10 / 更换真实文件，验证结果变化

最后做一个文件扰动验证。用孔径五点零毫米的另一份新版图纸，明确替换当前输入。这是独立测试，不是生产变更批准。输入修订号随之变化，旧结论转为历史。重新调用模型后，系统必须从新文件重新提取，不能复用原来的答案。

## 03:56 11 / 新结果生效，旧报告保留

新结果显示，四点零到五点零毫米，差值变为一毫米。再查看历史分析，原来的零点五毫米和已评审报告仍然保留。智变链把识图、规则校验、证据核查和人工评审连在一起，让工程变更的影响更容易查清、说明和交接。
